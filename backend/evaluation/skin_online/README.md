# 旧版 15 张图片冒烟测试

测试日期：2026-07-18；重叠审计日期：2026-07-19。

这 15 张图片来自 `raghad-murad/clinical-skin-disease-images`，每类 3 张。旧版 MobileNetV2 在尚未用该数据源重新训练时得到 Top-1 4/15（26.67%）、Top-3 13/15（86.67%）。

本地 v2 训练完成后，通过 SHA-256 审计发现其中 9 张出现在新模型的训练集或验证集中，因此不能再把这 15 张图片称为独立外部测试，也不能用其结果宣传准确率。图片仅保留用于界面和接口冒烟测试。

当前 15 类开发指标以 [`../skin_expanded_v3_final_report.json`](../skin_expanded_v3_final_report.json) 的 760 张固定留出测试集为准。旧图片仍只用于接口冒烟，不构成独立评估。
