# 皮肤病变模型与训练资源

## 当前部署模型

- 架构：MobileNetV2，约 262 万参数。
- 运行格式：ONNX，10.35 MB；CPU 推理，不依赖 TensorFlow 或 PyTorch。
- 支持类别：特应性皮炎、湿疹、疣/传染性软疣、基底细胞癌、黑色素瘤。
- 来源：[Zeynepcklc/skin-mobilenetv2](https://huggingface.co/Zeynepcklc/skin-mobilenetv2)，MIT 许可。
- 原始 Keras 权重约 26.2 MB；项目内 ONNX 权重 SHA-256 为 `f68630720ea3afb2aff40557b091887006ad40c53b6f906674fd56bb30014374`。

该模型适合作为开发版初筛能力，但模型卡缺少独立外部验证和详细训练集审计，不能用于临床诊断。上线前应使用下述数据重新训练并由皮肤科专业人员验证。

## 首选训练资源：SCIN

[SCIN](https://github.com/google-research-datasets/scin) 由 Google Research 发布，包含 1 万余张用户手机拍摄的常见皮肤状况图片、皮肤科医生标签、症状和肤色信息。其已标注病例中多数为过敏、感染或炎症性问题，比 HAM10000 的皮肤镜肿瘤图片更符合本项目的日常拍照场景。

官方资源：

- 病例元数据：`https://storage.googleapis.com/dx-scin-public-data/dataset/scin_cases.csv`
- 医生标签：`https://storage.googleapis.com/dx-scin-public-data/dataset/scin_labels.csv`
- 图片根路径：`https://storage.googleapis.com/dx-scin-public-data/`
- 许可：[SCIN Data Use License](https://github.com/google-research-datasets/scin/blob/main/LICENSE)，要求保留署名和许可信息，并禁止尝试重新识别参与者。

项目提供快速子集下载器。默认按病例最高权重标签选择 8 个常见类别，每类最多 200 个病例，每个病例只下载首张图，并发下载：

```powershell
cd backend
.venv\Scripts\python.exe training\download_scin_subset.py
```

只生成清单、不下载图片：

```powershell
.venv\Scripts\python.exe training\download_scin_subset.py --metadata-only
```

建议训练类别为湿疹/皮炎、银屑病、癣、荨麻疹/虫咬、常见细菌感染、常见病毒性病变、痤疮/玫瑰痤疮、疥疮。高风险肿瘤提示建议保留为独立模型，不与常见炎症类别混为一次诊断。

## 其他资源

- [Fitzpatrick17k](https://github.com/mattgroh/fitzpatrick17k)：16,577 张、114 类，适合做肤色公平性和外部验证；部分原始链接失效，且采用 CC BY-NC-SA 3.0，不适合追求快速下载或商业使用的首选训练集。
- [HAM10000](https://arxiv.org/abs/1803.10417)：10,015 张常见色素性病变皮肤镜图，适合肿瘤性病变研究，但图片域与普通手机照片不同，不应作为日常皮肤问题识别的唯一训练来源。

## 训练与验收要求

1. 必须按 `case_id` 划分训练、验证和测试集，避免同一病例的多张照片泄漏到不同集合。
2. 主指标使用 macro F1 和每类召回率；高风险类别单独报告敏感度，不能只看总体准确率。
3. 按肤色、年龄组和拍摄类型分别评估，并保留外部测试集。
4. 加入“无法判断/超出类别”拒识机制；当前接口在最高概率低于 60% 时明确标记低置信度。
5. 任何面向真实用户的版本都需要皮肤科专业审阅、隐私评估和符合当地医疗软件法规的验证。
