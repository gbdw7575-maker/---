# 皮肤病变模型与训练资源

## 当前部署模型

- 运行格式：ONNX；CPU 推理不依赖 TensorFlow 或 PyTorch，影像不会发送给云端模型。
- 支持类别：痤疮/酒渣鼻、光化性角化、特应性皮炎、常见细菌感染、基底细胞癌、接触性皮炎、湿疹、常见真菌感染、疱疹相关皮损、黑色素瘤、银屑病/扁平苔藓样皮损、脂溢性角化/良性肿物、鳞状细胞癌、荨麻疹、疣/传染性软疣。
- 当前部署 15 类 EfficientNet-B0 与 MobileNetV3-Small 双本地模型，验证集选择的概率权重为 90% + 10%；扩展权重缺失时回退到 5 类 v2，再缺失时回退到开发版 MobileNetV2。
- 回退模型来源：[Zeynepcklc/skin-mobilenetv2](https://huggingface.co/Zeynepcklc/skin-mobilenetv2)，MIT 许可；SHA-256 为 `f68630720ea3afb2aff40557b091887006ad40c53b6f906674fd56bb30014374`。

该模型适合作为开发版初筛能力，但模型卡缺少独立外部验证和详细训练集审计，不能用于临床诊断。上线前应使用下述数据重新训练并由皮肤科专业人员验证。

## 本地多分类训练

项目已提供完整的本地训练链路，支持 EfficientNet-B0 和 MobileNetV3-Small ImageNet 预训练骨干、数据增强、标签平滑、类别加权、冻结分类头预热和全模型微调。数据准备阶段会：

- 对 PAD 图片按患者分组后再切分，降低同一患者泄漏风险；
- 只将原始 `MEL` 或文件名明确标注恶性黑色素瘤的图片归入 MEL；
- 只将疣、verruca、molluscum 图片归入 WARTS，不把所有病毒感染混为一类；
- 全局删除字节完全相同的重复图片；
- 固定随机种子生成 70%/15%/15% 的训练、验证、测试集。

安装训练依赖并准备数据：

```powershell
cd backend
.venv\Scripts\python.exe -m pip install -r training\requirements.txt
.venv\Scripts\python.exe training\prepare_local_skin_dataset.py --limit-per-class 400
```

训练并导出 ONNX：

```powershell
.venv\Scripts\python.exe training\train_local_skin_model.py
.venv\Scripts\python.exe training\train_local_skin_model.py --architecture mobilenet_v3_small --output app\classifier\weights\skin_disease_expanded_v3_aux.onnx
```

训练完成后生成 ONNX 和同名 `.training.json` 报告。后端会在两份本地权重都存在时启用双模型融合；两者均由 ONNX Runtime 在 CPU 上运行。

### 2026-07-19 五分类 v2 结果（历史回滚版本）

- 下载候选 2209 张，标签和内容去重后保留 1992 张；训练/验证/测试分别为 1405/298/289 张，损坏图片为 0。
- 旧 MobileNetV2 基线：Top-1 35.29%，Top-3 84.43%。
- 新 EfficientNet-B0 单模型（ONNX）：Top-1 78.89%，Top-3 98.62%，宏召回 78.38%。
- 最终双本地模型（ONNX）：Top-1 79.58%，Top-3 99.31%，宏召回 78.73%，CPU 平均约 12.86 ms/张。
- 最终每类 Top-1 召回：AD 70.77%、BCC 98.67%、ECZEMA 67.19%、MEL 77.42%、WARTS 79.63%。

这些数字是开发数据内部留出测试结果，不是临床准确率。DermNet/SkinDiseases 来源缺少患者标识，只能按图片切分；PAD 来源已按患者切分。原先 15 张冒烟图片有 9 张与本轮数据重合，已明确作废为独立外部测试。

### 2026-07-19 十五分类 v3 结果（当前版本）

- 候选 5325 张，经标签冲突和内容去重后保留 5062 张；训练/验证/测试分别为 3546/756/760 张，损坏图片为 0。
- EfficientNet-B0 90% + MobileNetV3-Small 10% 的 ONNX 融合：Top-1 53.55%、Top-3 80.13%、宏召回 53.28%、宏 Top-3 80.72%。
- Top-1 较弱的 PSO 和 SCC，其 Top-3 候选召回分别为 63.64% 和 96.43%；因此输出必须称为候选相似类别，不能作为确定诊断。
- 详细逐类指标见 `backend/evaluation/skin_expanded_v3_final_report.json`。

十五分类与五分类准确率不能直接比较：类别数量从 5 增至 15，随机 Top-1 基线从 20% 降至 6.67%。这些仍是内部开发留出结果，不是临床验证；DermNet/SkinDiseases 来源仍缺少患者标识。

训练数据由公开聚合清单筛选十五个目标类，使用前必须同时检查各原始来源的许可和数据质量。生成的数据目录已加入 `.gitignore`，不得把医疗图片直接提交到仓库。

## 扩展常见病资源：SCIN

[SCIN](https://github.com/google-research-datasets/scin) 由 Google Research 发布，包含 1 万余张用户手机拍摄的常见皮肤状况图片、皮肤科医生标签、症状和肤色信息。其已标注病例中多数为过敏、感染或炎症性问题，比 HAM10000 的皮肤镜肿瘤图片更符合本项目的日常拍照场景。

官方资源：

- 病例元数据：`https://storage.googleapis.com/dx-scin-public-data/dataset/scin_cases.csv`
- 医生标签：`https://storage.googleapis.com/dx-scin-public-data/dataset/scin_labels.csv`
- 图片根路径：`https://storage.googleapis.com/dx-scin-public-data/`
- 许可：[SCIN Data Use License](https://github.com/google-research-datasets/scin/blob/main/LICENSE)，要求保留署名和许可信息，并禁止尝试重新识别参与者。

项目提供快速子集下载器。默认按病例最高权重标签选择 8 个常见类别，每类最多 200 个病例，每个病例只下载首张图，并发下载：

```powershell
cd backend
.venv\Scripts\python.exe training\download_scin_subset.py
```

只生成清单、不下载图片：

```powershell
.venv\Scripts\python.exe training\download_scin_subset.py --metadata-only
```

建议训练类别为湿疹/皮炎、银屑病、癣、荨麻疹/虫咬、常见细菌感染、常见病毒性病变、痤疮/玫瑰痤疮、疥疮。高风险肿瘤提示建议保留为独立模型，不与常见炎症类别混为一次诊断。

## 其他资源

- [Fitzpatrick17k](https://github.com/mattgroh/fitzpatrick17k)：16,577 张、114 类，适合做肤色公平性和外部验证；部分原始链接失效，且采用 CC BY-NC-SA 3.0，不适合追求快速下载或商业使用的首选训练集。
- [HAM10000](https://arxiv.org/abs/1803.10417)：10,015 张常见色素性病变皮肤镜图，适合肿瘤性病变研究，但图片域与普通手机照片不同，不应作为日常皮肤问题识别的唯一训练来源。

## 训练与验收要求

1. 必须按 `case_id` 划分训练、验证和测试集，避免同一病例的多张照片泄漏到不同集合。
2. 主指标使用 macro F1 和每类召回率；高风险类别单独报告敏感度，不能只看总体准确率。
3. 按肤色、年龄组和拍摄类型分别评估，并保留外部测试集。
4. 加入“无法判断/超出类别”拒识机制；当前接口在最高概率低于 60% 时明确标记低置信度。
5. 任何面向真实用户的版本都需要皮肤科专业审阅、隐私评估和符合当地医疗软件法规的验证。
